# 開口境界の縦隙間の調査と修正

対象は5e0e896の第四段階。変更前をstage4-before-opening-sealsタグで保存。本ターンにスクリーンショット本体は添付されていないため、画像で指定された壁のIDとの一致は未確定。下記は実データから再現した共通欠陥であり、画像の正規開口を塞いだものではない。

## 特定した境界

代表例：A周期R1（基本チャンクR1.1）西開口W、固定乗場F1との接続。R1位置(0,12.8,0)、固定乗場はX=-2.4〜-0.4、機械隙間X=-0.4〜0。W開口はZ=3〜5、幅2m、高さ2.1m。

外周壁：X=0〜0.12、開口の左右でZ=3または5を端とする。開口の奥まった上部パネル：X=0.14〜0.26。シャッター基準面はX=0.20、厚さ0.09。脇枠はX=0.06〜0.34、Z=2.9〜3および5〜5.1、Y=12.96〜15.06。上枠はY=15.06〜15.21。

脇枠が上枠付近で終わり、その上では外周壁内端0.12とパネル手前端0.14の間に20mmの帯が残っていた。開口の左右端を横切る斜めの視線が搬送側へ抜ける。これは0.4mの搬送離隔や、床渡し板の不足とは別の開口側面の欠損。R1では室内天井下のY=15.235、X=0.13、Z=3.025/4.975から左右へ0.06mのレイが、保存版では両方通過した。修正後は両方とも遮蔽。上部Y=15.8でも同様に確認。

## 修正規則

すべての搬送体の全方向の開口で、既存の脇枠と同じ断面0.1×0.28mの側面見切りを、開口高さ+0.16から外形上端6mまで連続させる。これにより20mmの未処理帯を覆い、残る開きは0mm（座標/レイ検査許容差1e-5m）。通行範囲a〜bは拡大も縮小もせず、左右の外側だけを補完する。

追加見切りは搬送体の外形内部に納まり、その搬送体と一体で移動するため、生活区域の接続時に他体と常時剛結しない。外側の格納継手は既存どおり搬送前に解除する。外形寸法、相手との離隔、搬送経路は維持。既存の露出面生成処理で枠・外周壁・上枠との重複を切り取り、共面を重ねて残さない。俯瞰では上部部材を切断表示し、探索では復帰する。

## 検証

- tests/opening-boundary.test.mjs：A/B/Cの全搬送体・全開口・左右端で、深さ0.13mの帯を局所レイ検査。東西南北を同じ生成規則で検証。
- R1では室内天井より下のレイも検査。保存版と修正版の同条件比較はevidence/opening-reproduction.json。
- 現行の全テストにより、正規継手横断、通常/高速歩行、扉、シャッター、同乗、A→B→C→A、0.2m離隔、近道、地図、NPC/2D訪問を回帰検査。
- scripts/check-seams.mjs：A/B/C×扉全閉/全開で、露出する同方向共面重複0。以前から区別しているR3シャッター下面の床内接触面のみ残る。
- 恒久連結体の内部境界、異高天井、継手床、側壁、再接続キャッシュも従来の幾何検査を維持。

管理プレビューでの実3D目視は未確認。指定画像の場所との一致は画像を再取得して確認する必要があり、画像の穴そのものが解消したと断定しない。今回、座標から特定した20mmの共通欠陥と再現レイの閉鎖は検証済み。
