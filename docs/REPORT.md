# 第四段階・追加修正：簡易個室の2D訪問と閉扉開始

現在はすべての通常扉を閉じて開始します。R3南側の扉は簡易個室の訪問入口です。廊下側からEまたは扉クリックで開くと、専用SVG画像 assets/resident-room.svg をimg要素で表示します。3Dカメラ固定や現在視点のキャプチャではなく、住人・寝台・机・棚を一定の構図で描いたオリジナル2D画像です。NPCは2体のままで、画像の住人は同じR3の住人を表します。

## チラつきの追加原因と修正

90度壁を別グループに置いた重なりを表面積で検査し、複数回再生成しても同じ露出面になる回帰テストを追加。接合部の床支持、側面と天井のレイ、異高天井、搬送後再生成、連続0.2m離隔を引き続き検査します。機械離隔・搬送時の継手解除を維持しています。

## 工程1：接合部の原因と修正

以前の継手は機械隙間の両端から0.26m延長した同じ床板を置き、チャンク床の上面と同じYで重なっていた。格子線の交差部も同じ高さに複数生成されていた。外周壁と足元部材、天井などの直交箱にも重複する面があった。完全閉鎖した開口ではマスクとシャッターが重複していた。

渡し床は機械隙間の範囲に限定し、チャンク床と面で接する形状に変更。格子線の交差を分割。壁・床・天井・枠の静的な直交箱は面を矩形分割して内包面と共面重複を除き、各露出面に一つの所有者を与える。完全閉鎖時の重複マスクを省略。シャッターの羽板にも露出面処理を適用する。接合カラーは床とは別の側壁・屋根を持ち、壁面との同一平面を避けた部材寸法に整理する。カメラ深度だけで隠す方法は使っていない。

継手は接続開放中のみ表示・支持床を持ち、シャッター閉鎖とともに解除される。搬送中には各体を剛結しない。全通行継手の身体横断、側面・上面・斜め視線の実メッシュ閉鎖、退避時の継手またぎ、全搬送包絡の検査を維持する。

形状原因への対処とCPU検査は完了。ただしGPUで視点を振ったときのチラつき消失は未確認のため、完成条件の目視合格とは区別する。

## 工程2：通常扉・2体のNPC

既存居室の扉を立体引き戸へ変更し、枠と0.65秒の開閉動作を追加。東翼4室にも通常扉を追加する。Eまたは近くからクリックで操作。開き切るまでは身体横断を許可せず、閉鎖する葉の全移動範囲にプレイヤーがいれば拒否する。引き戸の状態と局所位置を搬送後も保持する。施錠・鍵アイテムは追加していない。

NPCは合計2体。店主はT1局所(12,1.9)、住人はR3局所(1.55,6.25)。簡易立体モデル、頭、目、会話中の向き反応を持つ。店は常時営業、店内の自由移動を維持。住人の個室には寝台と棚があり、東側の実開口幅0.5mが身体直径0.7mより狭いため侵入できない。透明な不可視壁は使用しない。R3の通常扉から南側室内に入り、局所(3.55,6.15)から住人に話せる。

E会話は距離・所有区画・入口への直線通行空間を検査し、壁越しに開始しない。クリックは実メッシュの前方遮蔽と距離を検査。二行の会話をE・Enter・次へで進め、終了後に探索へ戻る。画面の「戻る」とSでも終了。人物は身体衝突対象で、所属搬送体とともに動く。

## 工程3：会話カメラ

同じ3Dシーンを継続表示する。店主ではプレイヤーの立ち位置を保ち、必要な視線補正を行う。個室ではR3局所カメラ(3.55,1.7,6.15)から、局所(1.5,1.35,6.25)を見る。0.32秒のsmoothstep補間と回転補間を用い、終了時も同じ身体位置・元の視線へ戻る。カメラは各フレームで搬送体相対座標から再計算する。

会話中は身体移動と搬送開始を抑止。Sは終了だけを行い、戻り補間が終わってから歩く。会話パネルは画面下部に置き、個室の顔の中心を避ける。

## 工程4：音

Web Audioのオシレーターと低域フィルターで、低い環境音、搬送移動音、シャッター、EV、引き戸、着床・戸当たり音を生成。外部録音の利用はない。

「音声を有効にする」という明示的なユーザー操作でAudioContextをresumeする。音量・ミュートあり。移動区間、閉鎖・開放、EV稼働、扉補間に同期し、搬送体とEVは距離減衰する。一時停止中は機械ループを止める。対応しないブラウザでも無音のまま探索可能。

状態連動モデルを自動検査した。実機の音声有効化・ミュート・音量・聴感の確認は未実施。
