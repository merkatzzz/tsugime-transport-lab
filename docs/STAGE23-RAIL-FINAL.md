# 第23段階 最終小修正

変更はトロッコ操作と観察乗降口のみ。

main.js：停車乗車中のマウス・矢印キー視点入力を停止。
stage22-session.js：停車・乗車後0.25秒で進路へカメラを回転し固定。選択後は既存座席旋回、走行中は自由視点。観察ゲートは車両が観察駅へ正しく停車した場合のみ開き、衝突世界も更新。
stage21-controls.js：描画が書き換えたinnerHTMLとの比較による矢印の定期再生成を廃止し、停車状態・選択肢の変化時だけ生成。旋回中は非表示。
stage21-view.js：固定カメラから見た実際の曲線を投影して矢印を配置。左右の斜めは↖/↗、前は↑、後方は↶。固定三方向メニューを廃止。選択時は通常カーソル。
stage21-world.js：観察足場の中央2mだけを乗降口とし、渡し床と停車連動ゲートを追加。危険外周の柵は維持。比較用独立実験は変更しない。
