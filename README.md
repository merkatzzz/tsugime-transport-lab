# 継ぎ目の部屋 — 第三段階・密集建築と近道の生成

本編とは独立した建築・搬送研究用プロトタイプ。12搬送体・19基本セルを、第二層 y=0m、第三層 y=12.8m、搬送デッキ y=6.4mに配置します。生活域は4列×3行、33.2×24.8m。基本外形8×8×6m、必要機械離隔0.2mです。

## 起動

Node.js 22以上とPython 3を使用。追加npm依存・ビルド・外部CDNは不要です。

- `npm start` → `http://localhost:8000`
- `npm test` → 第三段階54件（接続、歩行、18搬送計画、実メッシュ、UIのCPU配線確認）
- `npm run test:stage1` → 保存した第一段階24件
- `npm run test:stage2` → 保存した第二段階44件
- `npm run evidence` → 図面・接続図・搬送計画・比較JSONの再生成
- `npm run package` → 報告ページ・比較版・配布ZIPの再生成

検証結果を更新するときは先に `npm test > docs/evidence/test-output.txt 2>&1` を実行してください。静的サーバーでES Modulesを配信します。HTMLの直接ファイル起動には対応しません。

## 操作

WASD：3.6m/秒、Shift＋WASD：5.2m/秒。左右矢印またはドラッグで向きを変更。E：通常扉または固定EV。歩行速度は搬送速度設定から独立しています。

「搬送俯瞰」ではドラッグで回転、ホイールで拡大縮小。第三層・第二層を切断表示できます。切断表示だけ天井を非表示にし、一人称では実際の屋根・壁・継手トンネル・EV扉を表示します。

右側でA/B/Cの平面図、床の経路線、選択した搬送体の全開口、未到達の内部通路、空きドック、搬送デッキ上の保管・一時退避を確認できます。条件適用はAへのデバッグ初期化です。通常のA→B→C→Aでは最終位置の書き換えをせず、全区間を連続移動します。

## 近道を確認

同じ住戸301 R1局所(4,1.6)から、同じ生活用品店T1局所(7.2,5.4)までを比較します。両者は全周期で同じ世界位置です。

- A：南のJ1・J2とR2主通路を経由する35.13mの迂回。
- B：保管中だったT字廊下C0がR2の旧位置へ物理挿入され、R1→C0→T1の22.63m。約35.6%短縮し、第三層に独立な環状経路2本。
- C：C0が保管へ戻り、R3を経由する34.90mの迂回。

距離は身体半径0.35m＋余裕0.025mを用いた0.2m格子・8近傍の最短路です。解析的な連続空間の厳密最短距離ではありません。0.1m格子でも34.97 / 22.57 / 34.73mとなり、短縮を確認。全経路を実際の移動コントローラーで再生し、実3Dメッシュへの身体高さのレイ判定にも合格しています。

## 孤立と退避

通常は内部通路単位の退避警告と新規入場制限を使います。J1の中でB→Cを開始すると退避を待ちます。「意図的な孤立を許可する」で残留するとCで孤立し、次のAで再接続します。C0に残る実験ではC・Aの保管中は孤立し、次のBで再挿入されます。

R2の西A、西B、主通路は独立した3成分です。西Aが開いても西BはA/Cでは閉、Bでは0.5m重なりの視認専用です。搬送体全体への到達を、内部の全開口への到達とみなしません。

継手をまたぐ身体がいる間も搬送を待ちます。「デバッグ復帰」は固定乗場への強制移動で、通常の出口には数えません。

## 採用条件

一回り拡張41.6×33.2m・予約付き協調搬送・1デッキを初期値に採用。循環68.93秒。同程度33.2×24.8mでも72.93秒で成立します。二回り50×41.6mは今回の計画では改善しません。同程度案のみC0を生活域直下に保管し、大型搬送体を生活階の空欄へ仮着床します。拡張案ではC0保管とH1一時退避を別のベイに分離します。全案の完成生活配置は共通です。時間は1倍速・警告と開閉を除きます。

## ファイル

- `dist/src/architecture.js`：形状、4方向・個別ポート、内部成分、配置。
- `dist/src/transport.js`：占有セル、連続衝突、水平経路、協調予約。
- `dist/src/simulation.js`：身体移動、退避、搬送同乗、固定EV。
- `dist/src/view.js`：実メッシュ、異高接合部、連続EV昇降路。
- `dist/src/navigation.js`：最短路とコントローラー再生。
- `dist/src/maps.js`：実形状に基づく地図。
- `docs/REPORT.md` と `docs/evidence/`：検証報告、SVG図面、接続図、比較JSON、全搬送計画。
- `stage1/`、`stage2/`：改変前の独立ソース・テスト・報告。
- `dist/stage1/`、`dist/stage2/`：ブラウザで旧版を比較する入口。

## 検証の限界

この環境では `sites-preview` が中継ポート4173の準備待ちでタイムアウトし、ブラウザの一人称3D試遊・GPU描画は未確認です。CPUの実Three.jsメッシュに対する包絡・視線・歩行空間検査と、シミュレーションの自動再生を実施しました。手動試遊やスクリーンショットで確認済みとは扱いません。

搬送機構の荷重、レール・アクチュエーター、構造耐力、設備接続、加速度、法規、経路の大域最適性は対象外です。比較対象の小規模計画で成立することを検証しています。
