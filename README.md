# 『継ぎ目の部屋』建築・搬送システム独立実験

8搬送体・15チャンクを持つ、ブラウザで独立起動できる3Dプロトタイプです。既存ゲームのソース・セーブ・公開先とは分離しています。Three.js本体のみ添付ZIPから再利用し、建築・搬送・探索・地図のコードは新規作成しました。

## 起動

Python 3がある環境で、このフォルダ内から実行します。ネット接続・npm依存パッケージは不要です。

```sh
python3 -m http.server 8000 --directory dist
```

ブラウザで `http://localhost:8000` を開きます。ES Modulesを使用するため、HTMLを直接ダブルクリックする `file://` 起動には対応しません。WebGL対応のChrome・Edge・Firefoxを推奨します。

## 操作

| 操作 | 内容 |
| --- | --- |
| 搬送俯瞰 / 3D探索 | カメラ切替。俯瞰は外壁・天井を取り除いた開発表示 |
| 俯瞰でドラッグ / ホイール | 回転 / 拡大縮小 |
| WASD / ↑↓ | 衝突判定のある歩行 |
| ←→ / 探索中のドラッグ | 向き / 視線 |
| E | 通常扉の開閉、EV乗場で呼出、かご内で階移動 |
| 次周期へ搬送 | A→B→C→A。必ず物理経路を移動 |
| Ⅱ / ▶ | 警告・搬送・EVを一時停止 / 再開 |
| 速度 | 実験時間の0.5〜8倍。歩行速度は変化しない |
| 配置計画A/B/C | 地図で計画比較。実配置は変わらない |
| 区画を地図で選択 | 外形、室内高、接続幅、到達状態の詳細 |
| Aに初期化 | 全実験状態のリセット。通常移動ではない |
| デバッグ復帰 | 第三層の固定回廊へ瞬間復帰。通常の出口として扱わない |

タッチでは画面ドラッグと移動ボタンを利用できます。実機での操作感の調整は別途必要です。

## 設計値と実装

- 座標は東 +X、南 +Z、高さ +Y。北は −Z。
- 基本外形は8×8×5m。全チャンクを搬送占有に含めます。
- 第二層の床基準Y=0m、第三層Y=24m、専用搬送デッキY=11m。実床面は基準+0.16m。
- 一般居室の室内高3.2m、店舗3.5m、L字集会室4.1m、共用広間4.5m。
- 固定回廊の幅4m。搬送体内は偏心した1.5〜3.5mの廊下、広い店舗通路、45度の内部通路。
- 乗員は幅0.7mの円柱として扱い、壁端を含め必要な開口重なりを0.82mとします。ジャンプ・しゃがみはありません。
- 床支持、実壁線分、通常扉、シャッター、家具に対する歩行判定。地図と3Dは同じ建築定義を参照します。
- 接続グラフの通行・視認・遮断と、通常扉の施錠を区別します。BのR4は北開口の重なり0.4mで視認のみ。

| 搬送体 | 恒久連結数 | 主な空間 |
| --- | ---: | --- |
| R1 | 1 | 個室、短い前廊下、厚い構造壁 |
| R2 | 1 | 規格の1〜3号室、幅広廊下。2号室は施錠、3号室は観察窓 |
| R3 | 1 | 個室、1.5mの細廊下、1.6m厚の未使用構造帯 |
| R4 | 1 | 偏心入口の観察居室。Bの孤立対象 |
| T1 | 2 | 16mの間口を持つ開放的な生活用品店 |
| T2 | 2 | 小売店と通常扉から入る奥の店舗 |
| H1 | 4 | 16×16m、室内高4.5mの共同広間 |
| L1 | 3 | L字の集会室・休憩翼、チャンク内45度通路 |

## 3周期と搬送

各生活階には西から幅8・8・16・16mのドックがあります。固定回廊は全周期で残ります。第二層の東端には4×4mの固定観察室（X=48〜52、Z=4〜8）があり、AではL1の側壁で到達できず、B・CではH1の東口と接続して入れます。観察室も固定設備として全経路の衝突検査に含みます。

| 周期 | 第三層 西→東 | 第二層 西→東 | 回廊から到達 |
| --- | --- | --- | --- |
| A | R1 / R2 / T1 / H1 | R3 / R4 / T2 / L1 | 8/8搬送体。固定観察室は閉鎖 |
| B | R3 / R1 / T2 / L1 | R4 / R2 / T1 / H1 | 7/8。R4は視認のみ。固定観察室は新規接続 |
| C | R2 / R4 / T1 / L1 | R1 / R3 / T2 / H1 | 8/8搬送体 |

各遷移は、5秒の警告→シャッター閉鎖→第二層4体をデッキへ→遠方ベイZ=64へ並行退避→第三層4体をデッキへ→近方ベイZ=40へ並行退避→近方側から1体ずつ復帰→再固定・開放、の順です。

復帰時はZ=20の横行路でXを合わせます。上下移動はドック位置で行い、回転は使用しません。近方ベイを先に空けるため、遠方からの帰還を塞ぎません。高さ5mの外形を持つ搬送体は、専用デッキ上でY=11〜16mを占有します。第二層Y=0〜5m・第三層Y=24〜29mと重なりません。固定EVはX<−2、固定回廊はZ<0で搬送域から分離します。

遷移の移動時間はA→B 82秒、B→C 84秒、C→A 82秒（1倍速、警告・開閉を除く）。既定2倍では約45秒で1遷移します。リセット以外で配置を直接交換する処理はありません。

## 孤立実験

通常モードでは、A→Bに際しR4への新規入場を警告中から制限します。在室中の場合は搬送開始を退避完了まで待ち、固定回廊へ歩いて出られます。身体が継ぎ目をまたいでいる場合も閉鎖を待ちます。C→Aでは固定観察室も孤立するため、同じ保護を適用します。

「意図的な孤立を許可する」を有効にしてAの第二層R4に残ると、搬送に追従してBで孤立します。細い北隙間から回廊を視認できますが歩いて出られません。次のB→C搬送を実行するとR4ごと第三層の広い接続口へ運ばれ、物理的に再接続します。周期操作はデバッグ用の全域操作です。別経路・救助搬送体は今回は未実装です。

## 検証と資料

Node.js 20以降で `npm test`。24テストを含みます。詳細な結果、最終7問への回答、孤立方式の比較と制約は [検証報告](docs/REPORT.md) を参照してください。平面図と搬送経路図は `docs/evidence/` にあります。ブラウザによる3D描画・試遊は接続制約で未確認です。実メッシュの外形内収容と視線はCPUで追加検査しています。

図面を更新するには `node scripts/export-evidence.mjs`、報告ページと配布ZIPを再生成するには `python3 scripts/package.py` を実行します。

`dist/src/architecture.js` が寸法・建築・開口、`transport.js` が搬送計画・連続衝突判定、`simulation.js` が探索・搬送・退避・EV、`view.js` がThree.js描画、`maps.js` が同じデータからの地図を担当します。

## 制約

ガントリーの支持・駆動は理想化しています。剛体外形の運動学的成立を検証しますが、構造強度・重量・加減速荷重・振動・設備の給排水や電源の継手・建築法規は未検証です。全15チャンクの固定8ドックと退避空間を対象とし、任意形状・任意配置の自動経路計画を証明するものではありません。

WebGLが使えない場合も計算・地図は動きますが、3D探索の代替にはなりません。永続セーブは使用しません。読み込み直しでAに戻ります。
